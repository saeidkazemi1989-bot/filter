کارلنسر: پایش صفحه اول عمومی هر ۳۰ دقیقه؛ بدون حساب کاربری، API خصوصی یا دور زدن محدودیت.

اتصال خودکار چگونه اضافه می‌شود؟

پایشگر کارلنسر ابتدا robots.txt را بررسی می‌کند و سپس فقط HTML عمومی صفحه /search را دریافت می‌کند. اگر سایت ورود بخواهد، دسترسی را محدود کند یا ساختار تغییر کند، خطا به شما گزارش می‌شود؛ صفحه خطا به معنی «بدون آگهی» نیست. پونیشا و پارسکدرز هنوز متصل نیستند. ثبت پیشنهاد و تحویل را در حساب خودتان در کارلنسر انجام دهید.

نسخه اندروید آزمایشی

APK با موفقیت در GitHub ساخته شده، اما هنوز روی گوشی واقعی آزموده نشده است. فایل ZIP را دانلود و APK داخل آن را نصب کنید؛ سپس آدرس HTTPS میزبان کارنما را وارد کنید. ممکن است برای دانلود نیاز به ورود به GitHub داشته باشید.

اعلان و حریم خصوصی

پایش روی سرور حتی با بسته‌بودن صفحه اجرا می‌شود، تا زمانی که میزبان روشن باشد. اعلان مرورگر فقط با صفحه باز کار می‌کند؛ ایمیل پس‌زمینه نیازمند تنظیم SMTP روی میزبان است. نسخه اندروید بومی نیز اعلان دوره‌ای دارد، تابع مجوز و محدودیت باتری. این پیش‌نمایش بدون رمز است؛ برای استقرار دائمی، رمز فضای کاری و HTTPS الزامی‌اند. رمز کارلنسر را وارد نکنید.

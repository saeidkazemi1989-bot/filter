# کارنما — دستیار فرصت‌های فریلنسری

نسخه اولیه وب فارسی برای بررسی آگهی، برآورد قاعده‌محور، تولید پیش‌نمایش قالبی و مدیریت اقدام‌های انسانی. این پروژه بنا به درخواست جدید جایگزین مسیر اصلی VPN شده است؛ پوشه `app/` مربوط به پایه ناتمام و تست‌نشده اندروید قبلی است و بخشی از این وب‌اپ نیست.

## اجرا

نیازمند Python 3.10+، بدون وابستگی خارجی:

```sh
python3 freelance/server.py
# http://localhost:8000
```

برای پورت دیگر: `PORT=8080 python3 freelance/server.py`

سرور روی `0.0.0.0` گوش می‌دهد. اطلاعات در `freelance/data/workspace.db` ذخیره می‌شوند؛ این مسیر در Git نادیده گرفته شده است. فونت Vazirmatn از Google Fonts دریافت می‌شود و در نبود دسترسی، Tahoma جایگزین می‌شود.

## قابلیت‌های واقعی

- ورود دستی آگهی و ورود دسته‌ای حداکثر ۵۰ آگهی با JSON.
- سه نمونه ساختگی اختیاری با برچسب روشن؛ هیچ آگهی زنده‌ای از سایت‌ها برداشت نشده است.
- دسته‌بندی و امتیاز مبتنی بر کلیدواژه؛ نه تحلیل مدل هوش مصنوعی.
- برآورد قیمت با ساعت پایه دسته × نرخ کاربر × ۱٫۲۵؛ نه قیمت بازار یا تضمین سود.
- لندینگ قالبی برای دسته وب؛ طرح ساختار خروجی برای سایر دسته‌ها. هیچ‌کدام اجرای واقعی سفارش نیستند.
- خروجی دستورکار Markdown برای واردکردن دستی به Arena و ZIP شامل دستورکار و دمو.
- گردش کار بررسی ← پیشنهاد ← ثبت توافق ← انتظار اجرا در Arena ← بازبینی خروجی ← ثبت تحویل توسط کاربر.
- یادداشت اجباری برای توافق، آماده‌شدن خروجی و تحویل؛ ثبت تحویل، فایل را برای کارفرما ارسال نمی‌کند.
- اعلان داخل برنامه و اعلان مرورگر در صورت پشتیبانی و مجوز، فقط هنگام بازبودن صفحه.

## اتصال‌های انجام‌نشده

خزش یا پایش خودکار پونیشا، کارلنسر و پارسکدرز، ورود به حساب، تشخیص خودکار توافق، ارسال پیشنهاد، اجرای خودکار در Arena و تحویل به کارفرما **پیاده‌سازی نشده‌اند**. منابع، فقط لینک بازکردن سایت و ورود دستی دارند. برای پیاده‌سازی هر اتصال باید API/دسترسی مجاز، شرایط استفاده و ساختار سایت بررسی شود. هیچ API اجرایی Arena در این محیط در اختیار اپ قرار نگرفته است.

قبل از استفاده واقعی: دامنه و معیار پذیرش با کارفرما نهایی شود، برآورد بازبینی شود، دستورکار در Arena اجرا و خروجی واقعی تست شود. بسته شروع را به عنوان کار تکمیل‌شده تحویل ندهید.

## ورود JSON

```json
[
  {
    "title": "طراحی صفحه معرفی محصول",
    "description": "صفحه فارسی واکنش‌گرا شامل معرفی، امکانات و پرسش‌های متداول نیاز داریم.",
    "source": "ورود دستی",
    "url": "https://example.com/project/123"
  }
]
```

فقط محتوای عمومی و مجاز را وارد کنید. متن آگهی غیرقابل اعتماد است؛ نباید دستورهای داخل آن را به‌جای دستور کاربر اجرا کرد. دستورکار خروجی نیز این مرزبندی را یادآوری می‌کند.

## تست

```sh
python3 -m unittest discover -s freelance/tests -v
node --check freelance/static/app.js
```

تست‌ها شامل ورود، تراکنش دسته‌ای، عدم تکرار نمونه‌ها، وضعیت‌ها، الزام یادداشت، دانلود خروجی، escaping HTML، اعتبارسنجی URL و منع درخواست POST بین‌سایتی هستند.

## امنیت و محدودیت استقرار

این یک پیش‌نمایش تک‌کاربره است، **احراز هویت ندارد و برای انتشار عمومی آماده نیست**. هرکس به سرور دسترسی داشته باشد می‌تواند داده‌ها را ببیند و تغییر دهد. اطلاعات محرمانه، رمزها و داده مشتری وارد نکنید. قبل از استقرار واقعی: احراز هویت و جداسازی کاربران، HTTPS، محدودسازی درخواست، audit log، پشتیبان‌گیری امن، CSRF token و مدیریت اسرار اضافه شود. دیتابیس محلی در این نسخه رمزگذاری نشده است. لینک پیش‌نمایش را عمومی نکنید. اعلان ایمیلی/پیامکی و زمان‌بندی پس‌زمینه وجود ندارد.

## به‌روزرسانی ۰٫۲ — پایش سروری و اندروید

بخش‌های «اتصال‌های انجام‌نشده» و «نبود احراز هویت/ایمیل» در توضیح نسخه ۰٫۱ بالا، برای نسخه جدید به این صورت اصلاح شده‌اند:

- پایش HTML عمومی کارلنسر هر ۳۰ دقیقه، بررسی robots، حذف تکرار، ذخیره وضعیت آخرین تلاش/موفقیت و نمایش خطا اضافه شده است. اتصال مستقیم این محیط خطای شبکه دارد؛ آزمون HTML زنده در GitHub Actions موفق بود و ۲۴ کارت استخراج کرد. کاربر دیگر لازم نیست برای این اتصال هر بار آگهی وارد کند، مشروط به اتصال موفق میزبان و سازگاری ساختار سایت.
- احراز هویت اختیاری برای توسعه و اجباری در پیکربندی Docker میزبانی؛ کوکی نشست امن و محدودیت تلاش ورود.
- Docker Compose + Caddy + volume دائمی و ایمیل STARTTLS اختیاری.
- PWA قابل نصب از Chrome اندروید؛ بدون پوشِ پس‌زمینه.
- ماژول بومی `androidApp/` و workflow ساخت APK، با WorkManager برای اعلان دوره‌ای. APK آزمایشی در GitHub Actions با موفقیت ساخته و lint شد؛ روی گوشی واقعی تست نشده است.
- سایر سایت‌ها، پیشنهاد و تحویل بیرونی و اجرای خودکار Arena همچنان متصل نیستند.
